# ua-outils-theme-files

Front-end files of the **Tools** section of [Univers Aquaponie](https://www.univers-aquaponie.com) (free pond and aquaponics calculators), staged here so they can be loaded into an unpublished Shopify theme copy for testing.

Generated by a build script from the project source. Do not edit these files by hand.

- `sections/`, `snippets/`, `templates/`: Liquid and JSON theme files
- `assets/`: CSS, JavaScript, data snapshots and images
